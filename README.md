# Анимации в терминале

Шестнадцать примеров на Python без сторонних библиотек:

```bash
cd /home/pc/projects/terminal-animations
python3 globe.py
python3 donut.py
python3 star.py
python3 eiffel.py
python3 satellite.py
python3 life.py
python3 cat_and_mouse.py
python3 cigarette.py
python3 monkey.py
python3 fireflies.py
python3 aquarium.py
python3 fireworks.py
python3 sandscape.py
python3 maze.py
python3 rain.py
python3 plasma.py
```

Остановить анимацию: **Ctrl+C**. Размер автоматически подстраивается под окно терминала.

`life.py` показывает «Игру жизни» Конвея без надписей: живые клетки рисуются квадратными блоками, по умолчанию меняется 10 поколений в секунду (`--fps` позволяет выбрать другую скорость). Анимация идёт до Ctrl+C, а когда поле замирает, создаётся новое случайное поле.

`cat_and_mouse.py` показывает кота, который непрерывно бежит за мышью: скорость их шага меняется независимо, а в небе чередуются день и ночь. Остановка — Ctrl+C.

`cigarette.py` показывает, как зажигалка поджигает сигарету: она постепенно тлеет, укорачивается и выпускает дым. Сцена повторяется до Ctrl+C.

`monkey.py` показывает вращающуюся объёмную голову обезьяны с тенями, мордой, глазами, ушами и мимикой. В цветном терминале используется 24-битный цвет и двойное вертикальное разрешение. Остановка — Ctrl+C.

`fireflies.py` бесконечно генерирует движение и мерцание светлячков над ночным лугом. `aquarium.py` оживляет рыб, пузырьки и водоросли. `fireworks.py` запускает случайные ракеты, рассчитывает разлёт искр и постепенно гасит их. Эти сцены вычисляют каждый кадр во время работы, подстраиваются под размер терминала и работают до Ctrl+C. Они также доступны без цвета через `--no-color`.

`sandscape.py` моделирует падение песка и течение воды по полкам, затем начинает новую сцену. `maze.py` шаг за шагом вырезает случайный лабиринт и строит следующий. `rain.py` генерирует капли, всплески, круги на воде и редкие молнии. `plasma.py` рассчитывает цветные волны от движущихся источников. Все четыре анимации бесконечны и поддерживают `--fps`, `--width`, `--height` и `--no-color`.

Все генеративные сцены, включая `life.py`, используют оранжевый акцент окружения `#ff9a3c` и тёплые оттенки из `orange_theme.py`. В режиме `--no-color` графика остаётся читаемой без ANSI-цветов.

Общие параметры:

```bash
python3 globe.py --fps 15
python3 donut.py --frames 100 --width 80 --height 24
python3 star.py --no-color
```

При выводе в файл или конвейер `life.py`, `cat_and_mouse.py`, `cigarette.py`, `monkey.py`, `fireflies.py`, `aquarium.py`, `fireworks.py`, `sandscape.py`, `maze.py`, `rain.py` и `plasma.py` продолжают работать до Ctrl+C; остальные примеры рисуют один кадр. Укажите `--frames`, если нужно ограничить число кадров.

## Запись анимации в GIF

Для `record_gif.py` нужен установленный `ffmpeg`. Скрипт запускает переданный Python-файл в псевдотерминале, записывает кадры и сохраняет GIF рядом с текущей директорией:

```bash
python3 record_gif.py monkey.py
python3 record_gif.py --seconds 8 --output monkey.gif monkey.py
python3 record_gif.py --seconds 12 --fps 15 --width 100 --height 30 life.py
python3 record_gif.py monkey.py --offline --seconds 30 --fps 15 --width 100 --height 32 --cell-width 13 --cell-height 25
```

Без `--seconds` запись длится 30 секунд. По умолчанию кадр имеет 80×25 символов по 16×32 пикселя, то есть **1280×800 пикселей**, и частоту 15 кадров в секунду. `--cell-width` и `--cell-height` управляют разрешением в пикселях, а `--width` и `--height` — детализацией исходной терминальной сцены. При `--offline` скрипт с функцией `render(t, width, height, color)` вычисляет все кадры с точным шагом времени: запись не зависит от скорости терминала и не начинается с пустого кадра. Этот режим следует использовать для доверенных Python-файлов, так как он импортирует их в процесс записи. Без него анимация захватывается из псевдотерминала. Аргументы после имени файла, не относящиеся к `record_gif.py`, передаются анимации при захвате из терминала.

Готовые GIF можно пересоздать командой `sh make_gifs.sh`. Обычные сцены сохраняются в 1280×800, а вращающиеся объекты — в 1300×800 с более плотной сеткой символов. Формат GIF ограничен 256 цветами на палитру; для идеально плавных градиентов нужен видеоформат.

Готовые GIF из папки `gifs` можно отправить последовательно командой `sh send_gifs.sh`. Скрипт проверяет наличие всех девяти файлов и прекращает работу при первой ошибке `send`.
